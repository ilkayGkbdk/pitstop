# Security

model-coach runs inside your Claude Code session. Its only network call is a daily `GET`
of the public `catalog.json` in this repository, and it sends nothing about you or your session.

If you find a vulnerability, please **don't open a public issue**. Report it privately
through [GitHub's private vulnerability reporting](https://github.com/ilkayGkbdk/pitstop/security/advisories/new).
You'll get an answer within a few days.
